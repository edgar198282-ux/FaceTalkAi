# Abaj TV — Data Safety draft

Privacy policy URL:
https://facetalkai-production.up.railway.app/privacy

## Data processed by the service
- Device identifier used to pair an Android TV device.
- Device model/name for device management.
- Telegram account data supplied by the user during account linking.
- App preferences such as language, favorites, recent channels and interface state.
- Service access/subscription status.
- Technical diagnostics required to keep the service working.

## Data use
- App functionality.
- Account/device linking.
- Saving and synchronizing user preferences.
- Security and abuse prevention.
- Diagnostics and support.

## Data sale
Personal data is not sold.

## Transport security
Network communication uses HTTPS.

## Account/data deletion
Users can request device disconnection and deletion of associated service data through Abaj TV support.

## Play build permissions
The Play Store Android TV build requests INTERNET only.
It does not request CAMERA, RECORD_AUDIO or REQUEST_INSTALL_PACKAGES.
